# MAGIC GUARD

Многостраничный статический сайт для GitHub Pages. Не требует установки зависимостей или сборки.

## Запуск

Откройте index.html в браузере или запустите любой статический сервер из этой папки.

## GitHub Pages

Загрузите файлы в корень публичного репозитория, ветка main. В Settings → Pages выберите Source → GitHub Actions. Затем запустите Publish MAGIC GUARD на вкладке Actions. Альтернатива: выберите Deploy from a branch → main → /(root); в этом случае workflow не требуется.

## Редактирование

- config.js: подтверждённые контакты, статистика, отзывы, сотрудники, руководители и адрес сервиса приёма заявок.
- app.js: тексты страниц, список услуг и сценарий чата.
- style.css: цвета, шрифты, адаптивная сетка и анимации.
- *.html: отдельные адреса страниц и метаданные.

Формат отзыва: `{name, city, object, text, rating, date}`. Формат участника команды: `{name, role, photo, tenure, text}`. Фотографии храните в репозитории и указывайте относительный путь. Не используйте фотографии без разрешения.

## Статус интеграций

GitHub Pages размещает только статические файлы. CRM, AI, телефония, CMS, распределение заявок и защищённая админ-панель не подключены. Чат — пошаговая форма, а не AI-модель. Пока leadEndpoint пуст, формы только скачивают черновик на устройство посетителя и прямо сообщают, что заявка не отправлена. Данные не сохраняются в localStorage и не попадают в GitHub.

Для реального приёма заявок нужен отдельный HTTPS-сервис. После публикации согласованных юридических документов задайте его URL в config.js. Он должен принимать JSON POST, валидировать данные на сервере, ограничивать частоту запросов, разрешать CORS только для домена сайта и возвращать 2xx только после сохранения заявки. Храните ключи CRM/Telegram исключительно на сервере. Для чата передаются object, city, details, name, phone, source, consent, consentVersion, submittedAt; для партнёров дополнительно company и type.

Перед коммерческим запуском заполните реквизиты, контакты и юридические страницы. Схема сети демонстрационная и не подтверждает действующее покрытие. Реальные отзывы, фотографии и количественные показатели не добавлены. Шрифт загружается с Google Fonts; при необходимости разместите лицензированный шрифт локально.

## Проверка

Проверьте desktop/mobile, навигацию по страницам, клавиатурное управление меню и категориями, весь путь чата, неверный телефон и скачивание черновика. При подключении сервера проверьте успешную отправку, таймаут и ответ с ошибкой. Синтаксис: `node --check app.js` и `node --check config.js`.
